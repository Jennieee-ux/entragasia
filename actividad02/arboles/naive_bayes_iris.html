Aplicacion de Naive Bayes al conjunto Iris

Este reporte aplica el clasificador Naive Bayes al conjunto Iris usando R. La variable objetivo es Species y los predictores son las medidas de sepalo y petalo.

Procedimiento

  1. Cargar e1071, caret y el conjunto iris.
  2. Dividir los datos con semilla 123: 70% entrenamiento y 30% prueba.
  3. Entrenar naiveBayes(Species ~ ., data = train_data).
  4. Evaluar con matriz de confusion y probar nuevas observaciones.

Codigo base usado

library(e1071)
library(caret)
data(iris)
set.seed(123)
train_index <- createDataPartition(iris$Species, p = 0.7, list = FALSE)
train_data <- iris[train_index, ]
test_data <- iris[-train_index, ]
modelo_nb <- naiveBayes(Species ~ ., data = train_data)
predicciones <- predict(modelo_nb, test_data)
cat("Dimensiones entrenamiento/prueba:\n")
print(dim(train_data))
print(dim(test_data))
cat("\nModelo Naive Bayes:\n")
print(modelo_nb)
cat("\nMatriz de confusion:\n")
print(confusionMatrix(predicciones, test_data$Species))
cat("\nNuevas observaciones:\n")
nuevos_datos <- data.frame(
  Sepal.Length = c(5.1, 6.7, 5.8),
  Sepal.Width = c(3.5, 3.0, 2.7),
  Petal.Length = c(1.4, 5.2, 4.2),
  Petal.Width = c(0.2, 2.3, 1.3)
)
print(nuevos_datos)
cat("\nPredicciones nuevas:\n")
print(predict(modelo_nb, nuevos_datos))
cat("\nProbabilidades:\n")
print(predict(modelo_nb, nuevos_datos, type = "raw"))

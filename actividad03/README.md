## Descripción del proyecto

Este repositorio contiene **3 sistemas expertos** desarrollados para la actividad integradora:

1. **Asesor de seriación ISC (SWI-Prolog + servidor HTTP):** Apoya al alumno, tutor o gestor en la elección de cursos respetando la seriación del plan de estudios de Ingeniería en Sistemas Computacionales y el desempeño académico del alumno.

2. **Asignador de programadores a proyectos (Tau-Prolog, corre en el navegador):** Controla qué personal (junior, avanzado o senior) se necesita y falta para cada proyecto de software según su nivel de complejidad.

3. **Control de ingredientes de un menú (Go):** Indica los ingredientes de un platillo, si están disponibles todos y cuáles faltan.

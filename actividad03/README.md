Descripción del proyecto
Este repositorio contiene 3 sistemas expertos desarrollados para la actividad integradora:

Asesor de seriación ISC (SWI-Prolog + servidor HTTP): apoya al alumno, tutor o gestor en la elección de cursos respetando la seriación del plan de estudios de Ingeniería en Sistemas Computacionales y el desempeño académico del alumno.
Asignador de programadores a proyectos (Tau-Prolog, corre en el navegador): controla qué personal (junior, avanzado, senior) se necesita y falta para cada proyecto de software según su nivel de complejidad.
Control de ingredientes de un menú (Go): indica los ingredientes de un platillo, si están disponibles todos, y cuáles faltan.
Estructura del repositorio
/punto1-swi-prolog   -> Sistema experto 1 (SWI-Prolog, servidor HTTP)
/punto2-tau-prolog   -> Sistema experto 2 (Tau-Prolog, HTML + JS)
/punto3-go           -> Sistema experto 3 (Go)
Cada carpeta tiene su propio README con instrucciones de cómo correr el sistema.
